# ArenaMobile — заготовка iOS-игры

Голый SwiftUI-каркас: три вкладки (Меню / Игра / Настройки), во вкладке «Игра» уже работает
настоящий, проверяемый на устройстве геймлуп (точка отскакивает от краёв канваса, счёт растёт
с каждым отскоком) — чтобы сразу было что тестировать, а не пустой экран. От этого можно расти
в любую сторону: подключить SpriteKit, свой рендер, или начать дёргать API вашего
Laravel-бэкенда.

Проект специально собран без `.xcodeproj` в репозитории — он генерируется автоматически из
`project.yml` инструментом [XcodeGen](https://github.com/yonaskolb/XcodeGen) на этапе сборки.
Это и есть ключевой трюк, который позволяет всё нижеописанное сделать **вообще без Mac**.

## Структура

```
ArenaMobile/
├── project.yml                  # описание Xcode-проекта (вместо .xcodeproj — его гененерит XcodeGen)
├── .github/workflows/ios-build.yml   # CI: собирает НЕподписанный .ipa на облачном Mac
└── Sources/
    ├── ArenaMobileApp.swift     # точка входа (@main)
    ├── GameState.swift          # состояние + игровой цикл (tick(dt:))
    ├── Views/
    │   ├── ContentView.swift    # корневой TabView
    │   ├── MenuView.swift
    │   ├── GameView.swift       # рабочее демо на SwiftUI Canvas + TimelineView
    │   └── SettingsView.swift
    └── Resources/Assets.xcassets
```

## Как это работает без Mac вообще

Собрать `.app`/`.ipa` можно только на macOS — это требование Apple, обойти его нельзя. Но
macOS не обязательно должна быть *вашей*: GitHub бесплатно даёт облачные Mac-раннеры для
GitHub Actions. А чтобы поставить .ipa на живой iPhone, Apple обычно требует Xcode для
подписи — но здесь это делает **Sideloadly**, программа для Windows, которая сама подписывает
.ipa вашим Apple ID и заливает на телефон по USB. Mac для этого шага не нужен вообще.

Итого связка: **GitHub Actions (собирает) → Sideloadly на Windows (подписывает и ставит)**.

## Пошагово

### 1. Залить проект на GitHub

Создайте новый репозиторий на [github.com](https://github.com/new) (можно приватный — сборка
всё равно бесплатна) и залейте туда содержимое этой папки:

```
cd ArenaMobile
git init
git add .
git commit -m "Initial iOS scaffold"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
git push -u origin main
```

Команды выше можно выполнить и на Windows — Git для Windows ставится штатно, macOS тут не
нужен ни на одном из этих шагов.

### 2. Дождаться сборки

При пуше в `main` сборка запустится сама (вкладка **Actions** в репозитории на GitHub → workflow
«Build unsigned iOS IPA»). Если нужно запустить вручную — там же кнопка **Run workflow**.
Сборка занимает обычно 5–8 минут.

### 3. Скачать .ipa

Когда сборка позеленеет — откройте её, внизу страницы будет артефакт
`ArenaMobile-unsigned-ipa`. Скачайте (это .zip), распакуйте — внутри `ArenaMobile-unsigned.ipa`.
Он **не подписан** — это нормально, подписывать будет Sideloadly на следующем шаге.

### 4. Установить Sideloadly

Скачайте [Sideloadly](https://sideloadly.io/) под Windows и установите. Если на компьютере
никогда не стоял iTunes — Sideloadly сама предложит поставить нужные Apple-драйвера
(Apple Mobile Device Support), без них Windows не увидит iPhone по USB.

### 5. Подключить iPhone

Подключите iPhone к компьютеру кабелем, разблокируйте, на всплывающий вопрос на самом
телефоне нажмите **«Доверять»**.

### 6. Подписать и установить

Откройте Sideloadly:
- перетащите `ArenaMobile-unsigned.ipa` в окно программы;
- сверху выберите ваш iPhone в списке устройств;
- в поле Apple ID введите свой **обычный** Apple ID и пароль (не пароль от App Store —
  обычный логин от аккаунта; при двухфакторке Sideloadly попросит одноразовый код). Это не
  публикует приложение и не отправляет ничего в App Store — так формируется бесплатный
  сертификат разработчика (personal team), тот же механизм, что использует сам Xcode;
- нажмите **Start**. Через минуту-две приложение появится на iPhone.

### 7. Довериться профилю на самом iPhone

При первом запуске iOS откажется открывать приложение от «неизвестного разработчика». Нужно
один раз зайти: **Настройки → Основные → VPN и управление устройством**, найти там ваш Apple
ID, зайти и нажать **«Доверять»**. После этого иконка на рабочем столе открывается как обычно.

## Ограничение бесплатного Apple ID

С обычным (бесплатным) Apple ID сертификат живёт **7 дней**, потом iOS сама снимает
приложение с телефона. Чтобы обновить — просто повторите шаги 6–7 ещё раз (после первого
раза это занимает буквально минуту). Если оставить Sideloadly запущенной в фоне с
подключённым телефоном, она умеет переустанавливать сертификат автоматически по расписанию —
это включается в настройках самой программы.

Альтернатива Sideloadly с похожим принципом — [AltStore/AltServer](https://altstore.io/)
(тоже под Windows), если Sideloadly почему-то не подойдёт.

Если в какой-то момент оформите платный Apple Developer Program ($99/год) — тот же .ipa можно
будет поставить через TestFlight (без недельной пляски с переподписью) или подписать сразу на
год; сам процесс сборки в GitHub Actions при этом не меняется.

## Честно про ограничения такого цикла разработки

Без Mac у вас не будет Xcode-превью (мгновенный live-preview экрана при правке кода),
симулятора и отладки breakpoint'ами на устройстве — только «поправил код → закоммитил →
подождал сборку 5-8 минут → переустановил через Sideloadly». Для доводки экранов это
медленно. Когда понадобится быстрая итерация — самый простой выход: временный доступ к Mac
(друг, облачный Mac вроде MacInCloud на пару часов) даёт Xcode с превью и симулятором прямо
поверх того же самого проекта — `project.yml` открывается в Xcode один в один, ничего
переделывать не придётся.

## Куда расти дальше

- Подключить **SpriteKit** или **RealityKit** вместо `Canvas` в `GameView.swift` — для
  настоящей 2D/3D-игры.
- Дёргать API вашего Laravel-бэкенда (`URLSession`/`async-await`) — например, показывать те же
  деревни/отчёты, что и в веб-версии.
- Сохранять прогресс через `SwiftData` или `UserDefaults`.
- Пуш-уведомления о завершении построек/атак.
